# Promt
"Genera el código completo para una aplicación Flutter profesional y modular del negocio 'Soriana Digital', estructurada en los siguientes archivos y carpetas:

1. Configuración Global (lib/main.dart):

Usa Rutas Nombradas (initialRoute: '/').

Crea un Scaffold principal con un BottomNavigationBar (TabBar inferior) de 5 opciones: Arroz (grain), Leche (water_drop), Carnes (kebab_dining), Aceite (oil_barrel) e Integral (eco).

El AppBar debe ser color amarillo Soriana (#F7C02F), con el título centrado y un logo circular blanco en la esquina derecha (URL: https://raw.githubusercontent.com/Antonio347Vania/im-genes-para-flutter-6toI-11-Feb-2026/refs/heads/main/logo.jpg).

2. Archivo de Diseño Base (lib/mis_paginas_tab/diseno_base.dart):

Crea una función pública llamada buildTarjetaSoriana(String nombre, String descripcion, String url).

El diseño debe ser una tarjeta estilo 'Column Layout' (380px de ancho) con fondo Naranja (Colors.orange) y bordes muy redondeados (radius: 25).

Interior de la tarjeta:

Arriba: Un contenedor blanco con bordes redondeados que ocupe casi todo el ancho, con la imagen del producto centrada (250px de alto).

Abajo: El nombre del producto en blanco negrita (fontSize: 28) y una descripción 'Producto de Calidad' en blanco translúcido.

El fondo de la pantalla debe ser color crema (#FFF9EB).

3. Carpeta de Pantallas (lib/mis_paginas_tab/):

Genera 5 archivos independientes (pantalla_arroz.dart, pantalla_leche.dart, etc.).

Cada archivo debe ser un StatelessWidget que importe diseno_base.dart y llame a la función buildTarjetaSoriana con su respectiva imagen de GitHub.

4. URLs de Imágenes de Producto:

Arroz: .../Arroz.jpg

Leche: .../leche.jpg

Carne: .../carne%202.jpg

Aceite: .../Aceite%20Aguacate.jpg

5. Requisitos de Código: Todo el código debe estar bajo Material 3, ser libre de errores de visibilidad de funciones y estar listo para producción modular."
